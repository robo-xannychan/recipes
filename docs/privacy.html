Privacy Policy

Last updated November 22, 2026.

Health Bot is a personal app used only by its owner. It accesses the owner's own Google Health data (activity, nutrition, sleep, body measurements, and related data) solely to log entries she asks for and to summarize her own data back to her.

  • Data is used only for the owner's personal health tracking.
  • Data is never sold, shared with third parties, or used for advertising.
  • Google user data is handled in line with the Google API Services User Data Policy, including its Limited Use requirements.
  • The owner can revoke access at any time from her Google Account's third-party access settings, and can delete any stored copies on request.

Questions can be raised through the owner's GitHub profile, robo-xannychan.
